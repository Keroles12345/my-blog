# My Blog

A Laravel-based blog application for practicing full-stack web development, server-side rendering, routing, database-driven features, and frontend asset management.

## Tech Stack
- PHP
- Laravel
- Blade
- Tailwind CSS
- Vite

## Getting Started

```bash
git clone https://github.com/Keroles12345/my-blog.git
cd my-blog
composer install
npm install
npm run build
php artisan serve
```

Configure your database and environment variables in `.env` before running migrations.
